# ✨ Daily Habit Tracker — React.js

A modern and beginner-friendly **Daily Habit Tracker** built with React.js. This project helps users manage daily habits, track completed tasks, and monitor their daily progress through a dynamic progress bar.

## 🌟 Features

- ➕ Add new habits
- ✅ Mark habits as completed or incomplete
- 🗑️ Delete habits
- 📊 Dynamic progress bar
- 📈 Track completed habits and overall progress
- 🎨 Modern purple-themed user interface
- 📱 Responsive design for different screen sizes
- 💜 Beginner-friendly React code

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## 📸 Project Preview

The Daily Habit Tracker features a clean dashboard with a habit checklist, completion indicators, and a progress bar.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Tanishka2744/daily-habit-tracker-react.git
```

### 2. Navigate to the project folder

```bash
cd daily-habit-tracker-react
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.
